# 拾句 · 微信读书桌面组件

一款 Android 应用，把你在微信读书里的划线显示在手机桌面。组件会展示原文、书名，以及能关联到该划线的个人想法；点「下一条」切换，约每 30 分钟自动轮播。应用每 6 小时尝试同步，也可以手动同步。

## 构建与使用

1. 用 Android Studio 打开此目录，安装 Android SDK 35，并使用 JDK 17 或更高版本。也可以运行 `gradlew.bat assembleDebug`。
2. 安装 `app/build/outputs/apk/debug/app-debug.apk` 到 Android 8.0 或更高版本的手机。
3. 在应用里输入自己的 `wrk-...` WeRead API Key，点击「保存并同步」。电脑上的环境变量不会自动传到手机。
4. 长按手机桌面空白处，在组件列表中添加「拾句 · 微信读书划线」。

密钥由 Android Keystore 加密并保存在设备上，不会写入源码或 APK。划线缓存在应用私有目录；「清除密钥和本地划线」会删除两者。组件本身会在桌面显示私人笔记，请按需使用。

## 数据来源与行为

- 用微信读书 Agent Gateway 的 `/user/notebooks` 列出有笔记的书；按 `count` 和 `lastSort` 读取全部页。
- 对每本书用 `/book/bookmarklist` 取个人划线；对有个人想法的书用 `/review/list/mine`，把有 `range` 或 `abstract` 的想法关联到划线。
- 书评和没有对应划线的普通想法不会显示。接口不提供书签内容，因此组件只展示划线。
- 同步失败时保留上一次成功的缓存。首次完整同步时间取决于有笔记的书籍数量和网络状况。
- 组件周期更新至少约 30 分钟一次，实际时间受 Android 系统调度影响。

接口请求均带 `skill_version: 1.0.4`。若服务端返回 `upgrade_info`，应用会停止同步并显示更新提示，需要升级接口适配代码。

## 两台电脑继续开发

项目已使用 Git。把 `main` 推送到自己的私有远程仓库后，在另一台电脑 `git clone <仓库地址>`，并用 Android Studio 打开克隆的目录。每次换电脑前先提交并推送：

```powershell
git add .
git commit -m "描述本次修改"
git push
```

换到另一台电脑时，先运行 `git pull --rebase`，再继续开发。构建产物、本机 SDK 路径、源码压缩包和签名文件都不提交。两台电脑默认的 Android 调试签名不同；如果要直接覆盖安装同一部手机上的调试版，需要使用相同签名，否则卸载旧调试版后重装并重新同步。
